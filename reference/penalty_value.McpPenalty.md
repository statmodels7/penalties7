# MCP Methods

The closed piecewise forms; see
[`mcp_penalty`](https://statmodels7.github.io/penalties7/reference/scad_penalty.md).

## Arguments

- pen:

  An `McpPenalty` object.

- beta:

  A numeric vector of coefficients.

- theta:

  A list containing `lambda` and `gamma`.

- scale:

  Handled by the generic.

- ...:

  Unused.

See the generic pages.
