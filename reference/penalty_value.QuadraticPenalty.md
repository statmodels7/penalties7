# Quadratic Penalty Methods

Closed form in \\\lambda\\ throughout; the Hessian is constant in
\\\beta\\, and the mixed block is \\D'PD\beta\\.

## Arguments

- pen:

  A `QuadraticPenalty` object.

- beta:

  A numeric vector of coefficients.

- theta:

  A list containing `lambda`.

- scale:

  Handled by the generic.

- ...:

  Unused.
