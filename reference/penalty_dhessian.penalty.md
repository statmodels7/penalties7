# What the Base Class Answers

Each of these rejects, naming what is missing. A marginal criterion is a
Laplace approximation and asks for derivatives beyond the second; a
penalty that does not supply them cannot be estimated by one, and
reporting that is better than a criterion assembled from a quantity
nobody wrote.

## Arguments

- pen:

  A
  [`penalty`](https://statmodels7.github.io/penalties7/reference/penalty.md)
  object.

- beta:

  A numeric vector of coefficients.

- theta:

  A named list of hyperparameters.

- ...:

  Unused.

## Value

Signals an error.
