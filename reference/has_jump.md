# Does the Log-Density's Slope Jump Across a Point?

Compares the derivative in the argument just either side of it.

## Usage

``` r
has_jump(d, theta, at, eps = 1e-05)
```

## Arguments

- d:

  A distributions7 object.

- theta:

  Where to read it.

- at:

  The candidate point.

- eps:

  How far either side.

## Value

A single logical.
