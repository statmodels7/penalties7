# How Many Blocks an Additive Penalty Repeats

Returns the `blocks` property as a single integer, reading an empty
value as 1.

## Usage

``` r
additive_blocks(pen)
```

## Arguments

- pen:

  An
  [`AdditivePenalty()`](https://statmodels7.github.io/penalties7/reference/AdditivePenalty.md)
  object.

## Value

A single integer of at least 1.
