# The Weighted Sum and Its Pseudo-Inverse

\\S(\lambda)\\ and the pseudo-inverse the log pseudo-determinant and its
derivatives are written in, from one eigendecomposition.

## Usage

``` r
additive_sum(pen, theta)
```

## Arguments

- pen:

  An `AdditivePenalty` object.

- theta:

  The aligned hyperparameter list.

## Value

A list with the matrix `S`, its pseudo-inverse `Sp`, and the log
pseudo-determinant `logpdet`.
