# Structured Penalty Methods

Every quantity from the structure's own contract; see
[`structured_penalty`](https://statmodels7.github.io/penalties7/reference/structured_penalty.md).

## Arguments

- pen:

  A `StructuredPenalty` object.

- beta:

  A numeric vector of coefficients.

- theta:

  A named list of the structure's free values.

- scale:

  Handled by the generic.

- ...:

  Unused.
