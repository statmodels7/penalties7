# SCAD Methods

The closed piecewise forms; see
[`scad_penalty`](https://statmodels7.github.io/penalties7/reference/scad_penalty.md).

## Arguments

- pen:

  A `ScadPenalty` object.

- beta:

  A numeric vector of coefficients.

- theta:

  A list containing `lambda` and `a`.

- scale:

  Handled by the generic.

- ...:

  Unused.
