# The Piecewise Regions of SCAD and MCP

The sign, the absolute value and the region indicators of each element,
shared by every method below.

## Usage

``` r
scad_parts(t, lam, a)

mcp_parts(t, lam, gam)
```

## Arguments

- t:

  The mapped coefficients \\Deta\\.

- lam, a, gam:

  The hyperparameters.

## Value

A list of vectors.
